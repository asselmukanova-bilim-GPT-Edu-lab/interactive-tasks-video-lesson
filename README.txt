ПРОМПТ ҚҰРАСТЫРУ — АВТОНОМНАЯ МИНИ-ИГРА

Запуск:
1. Откройте файл index.html двойным щелчком.
2. Интернет для работы игры не требуется.

Состав папки:
- index.html — страница игры;
- styles.css — оформление и адаптивная версия;
- script.js — механика конструктора, проверка и сохранение прогресса;
- fonts — локальный шрифт Montserrat.

Прогресс сохраняется в localStorage текущего браузера.
